# Программа для тренировки зрения · 1.0.0

## Установка на Windows 10

1. Войдите в Windows под учётной записью ребёнка.
2. На [странице последнего выпуска](https://github.com/IvanZakharov77/vision-break/releases/latest) скачайте файл `VisionBreak-Setup-*.exe`.
3. Запустите скачанный установщик. Он установит программу для текущей учётной записи без прав администратора, добавит её в автозапуск и запустит 40-минутный отсчёт.

Для просмотра экрана на Mac откройте `Preview.html` в браузере. Чтобы открыть 20-секундный пример на Windows из исходников, запустите **Demo.cmd**. Демо оставляет открытые приложения на месте и работает без автозапуска.

## Как работает перерыв

- После 40 минут программа один раз отправляет запрос на закрытие видимым окнам из списка. Если приложение ждёт подтверждения, его окно может остаться под таймером.
- На основном мониторе появится полноэкранный таймер на 20 минут. Чтобы отключить или включить тиканье, нажмите кнопку **Тиканье**. Выбор действует до выхода из учётной записи.
- Крестик отсутствует, Alt+F4 игнорируется. Когда время истечёт, экран закроется и сразу начнётся новый 40-минутный отсчёт.

## Как поменять список

Нажмите **Win+R**, вставьте `notepad "%LOCALAPPDATA%\VisionBreak\apps.txt"` и нажмите Enter. Укажите по одному имени процесса на строку. Имена можно посмотреть в диспетчере задач на вкладке **Подробности**. Сохранённый список будет применён при следующем перерыве. Начальный список включает Roblox и распространённые браузеры.

## Обновления

При запуске VisionBreak проверяет последнюю стабильную версию на GitHub. Если версия новее, в области уведомлений появится значок со ссылкой на страницу выпуска. Чтобы обновиться, скачайте и запустите установщик из учётной записи ребёнка. Установщик сохранит `apps.txt`. При отсутствии сети отсчёт работает как обычно.

Рядом с установщиком в выпуске есть файл `.sha256`. Сравнить хеш можно командой PowerShell `Get-FileHash -Algorithm SHA256 .\VisionBreak-Setup-1.0.0.exe`. Установщик без цифровой подписи.

## Удаление

Откройте **Параметры → Приложения → VisionBreak → Удалить** под той же учётной записью. Программа остановится, ярлык автозапуска будет удалён, а список приложений сохранится.

## Сборка из исходников

`Build.cmd` собирает `VisionBreak.exe` штатным компилятором .NET Framework 4.x. `Install.cmd` и `Remove.cmd` позволяют установить и удалить сборку из исходников. Для обычной установки используйте установщик из выпуска.

## Проверка на Windows

В распакованной папке запустите `Build.cmd --test` из командной строки. Для ручной проверки откройте **Demo.cmd**, проверьте Alt+F4, переключение звука и автоматическое закрытие. После установки проверьте автозапуск при повторном входе, а через 40 минут проверьте закрытие двух окон из списка и появление таймера на 20 минут.
